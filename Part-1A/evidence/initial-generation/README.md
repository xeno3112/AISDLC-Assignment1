# Initial-Generation Evidence

This directory is reserved for the **first complete application
implementation**, before any repair attempt. Preserve its implementation
reference, generation timestamp, approved specification/task references, and
baseline `./.harness/run-harness.sh` summary. Link or copy the corresponding
immutable structured run from `../harness-results/`.

The first complete implementation baseline is recorded in
[initial-run.json](./initial-run.json), with its immutable structured output in
[the harness-results directory](../harness-results/). The baseline is recorded
before the branch-coverage repair; its only failing gate is documented without
rewriting or replacing the result.
